---
title: "Instruction Set Architectures"
published: "2026-09-30T19:22:00Z"
---

Instruction Set Architectures (ISAs) like x86-64 are what determine the actual byte sequences a compiler outputs for the specified ISA.

Those byte sequences then map literally to instructions on the CPU.

source code -> compiler targeting an ISA -> machine-code bytes -> CPU decodes bytes and executes instructions

They are like they key that defines the values a compiler can output to map to instructions for a CPU.
